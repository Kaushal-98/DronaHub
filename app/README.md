# 🎓 DronaHub

> **Your college resources, all in one place.**

DronaHub is a centralized student resource platform designed to make academic resources easier to access, organize, and share. It provides students with a single platform for discovering **PYQs, notes, study materials, useful resources, and academic opportunities**.

---

## ✨ Overview

Students often struggle to find the right academic resources at the right time. Important notes, previous year questions, study materials, and useful information are usually scattered across different platforms and groups.

**DronaHub solves this problem by creating a centralized student-focused platform** where resources can be easily discovered, accessed, and shared.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Kaushal-98/DronaHub.git
```

### 2. Navigate to the Project Folder

```bash
cd DronaHub
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will start on a local development server.

## 🎯 Problem Statement

College students often face problems such as:

* Important resources being scattered across multiple platforms.
* Difficulty finding Previous Year Questions.
* Lack of centralized study materials.
* Missing useful opportunities due to delayed information.
* Dependency on multiple WhatsApp groups and online platforms.
* Difficulty in sharing academic resources efficiently.

DronaHub aims to solve these problems by providing a **single centralized platform for students**.

---

## 💡 Solution

DronaHub brings important student resources together in one place.

Students can:

* Discover useful academic resources.
* Access notes and study materials.
* Find Previous Year Questions.
* Share useful resources with the community.
* Stay connected with relevant student information.

The goal is to make student resource discovery **simpler, faster, and more organized**.
